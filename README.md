# 🤖 AI Chatbot (Local LLM)

A full-stack AI chatbot built using modern web technologies and a locally running LLM.

---

## 🚀 Tech Stack

* **Frontend:** React + Tailwind CSS
* **Backend:** Node.js + Express
* **AI Engine:** Ollama (Gemma 2B model)

---

## ✨ Features

* 💬 Real-time chat interface
* ⚡ Fast responses using local LLM
* 🔒 No API cost (runs completely locally)
* 🎨 Clean UI with Tailwind CSS
* 🔗 Full-stack architecture (React ↔ Express ↔ AI)

---

## 🧠 How It Works

```text
User → React (Frontend)
     → Express (Backend API)
     → Ollama (Local AI)
     → Gemma Model
     → Response → UI
```

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/ai-chatbot.git
cd ai-chatbot
```

---

### 2️⃣ Install dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd ../frontend
npm install
```

---

### 3️⃣ Run Ollama

Make sure Ollama is installed.

```bash
ollama run gemma:2b
```

---

### 4️⃣ Start backend

```bash
cd backend
node server.js
```

---

### 5️⃣ Start frontend

```bash
cd frontend
npm run dev
```

---

## 🌐 Local URLs

* Frontend → http://localhost:5173
* Backend → http://localhost:5000

---

## ⚠️ Note

* This project uses a **local LLM**, so no internet API is required.
* Make sure Ollama is running before sending requests.
